# Barbearia Studio — portfólio

Demonstração de site para barbearia: serviços, cálculo de orçamento, duração estimada e agenda simulada.

## Como executar
Abra `index.html` no navegador ou use Live Server. Compatível com hospedagem estática como GitHub Pages.

## Limitações importantes
- **Não é um serviço real de agendamento.** As simulações ficam apenas no `localStorage` do navegador e não são compartilhadas entre dispositivos.
- **Não digite dados pessoais reais.** Use nomes e telefones fictícios para demonstração.
- Não há login nem autenticação. A antiga senha fixa foi removida.
- Horários e valores são exemplos para portfólio.

## Arquivos
- `index.html`: apresentação
- `index3.html`: serviços e formulário de simulação
- `index2.html`: agenda local de demonstração
- `style.css`: estilo responsivo
- `script.js`: orçamento e lógica de simulação
